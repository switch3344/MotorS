# MotorServiceKRD

Сайт автосервиса на React + TypeScript + Vite, Tailwind CSS, GSAP и Three.js. Текущая версия включает шапку, hero с тахометром, интерактивную модель V12 с услугами и футер.

Сайт: https://switch3344.github.io/MotorS/

Репозиторий: https://github.com/switch3344/MotorS

## Запуск

```powershell
npm ci
npm run dev
```

Для адреса текущего предпросмотра:

```powershell
npm run dev -- --port 5174 --strictPort
```

Проверка и production-сборка:

```powershell
npm run check
npm run build
npm run preview -- --port 5174 --strictPort
```

Если порт занят открытым предпросмотром, остановите его либо выберите другой порт.

## Публикация на GitHub Pages

Workflow `.github/workflows/deploy.yml` устанавливает зависимости через `npm ci`, собирает проект и публикует `dist` при каждом push в `main`. В Settings → Pages выбран источник GitHub Actions. Запуск вручную доступен во вкладке Actions.

В workflow задан `VITE_BASE_PATH=/MotorS/`. Пути к логотипу, моделям и изображениям учитывают этот префикс. Локально используется корень `/`. При переименовании репозитория обновите переменную в workflow.

Настройка соответствует официальным инструкциям [Vite](https://vite.dev/guide/static-deploy.html#github-pages) и [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Текущий экран

- Чёрная рамка 10 px, мобильная 8 px; тёмная hero-карточка с радиусом 44/28 px.
- Фон однотонный #131416. В hero нет видео, изображения, шума и фоновых иллюстраций.
- Шапка-вырез с вогнутыми ушками, исходный логотип пользователя, белые кнопки с красной стрелкой. Меню телефона работает, Escape закрывает его.
- Заголовок в две строки с красным курсивным словом «вперёд», подзаголовок и запись через Telegram.
- По последней обратной связи убраны бейдж «Гарантия 5 лет», крупный цифровой счётчик и подпись «Тест на пределе».
- Это тахометр: шкала 0–8, единицы ×1000 об/мин. На телефоне подписи 0, 2, 4, 6, 8. Красная зона начинается с 6500 об/мин.
- Ускорение до 6200–7000 об/мин занимает 2–3 секунды. При переключениях 1→2→3→4→5 обороты падают за 240 мс до 3800–4600, затем снова растут. После пятой передачи цикл плавно возвращается к холостым 900 об/мин.
- Номер передачи используется внутри анимации и доступен в aria-valuetext, визуальной плашки нет.
- GSAP анимирует обороты по времени; скролл не управляет стрелкой. IntersectionObserver повторяет цикл при новом входе hero в область просмотра. Вне экрана и при скрытой вкладке анимация приостановлена.
- prefers-reduced-motion оставляет стрелку статичной на 4000 об/мин.
- В шапке показаны неактивные названия будущих разделов; запись и Telegram работают. Состав секций будет согласован после проверки hero.

## Геометрия

SVG: viewBox 0 0 1600 900, preserveAspectRatio="xMidYMid slice". Десктоп: C=(800,2527), R=1967. Угол стрелки: −22° + (rpm / 8000) × 44°. Кончик стрелки находится на радиусе R−30; ось остаётся ниже карточки.

SVG сохраняет пропорции 16:9 и ширину карточки, чтобы все подписи оставались видны на портретном экране. Внешний hero обрезает продолжение стрелки. Вертикальное смещение рассчитывается по высоте карточки и нижней границе текста; подписи шкалы отделены от кнопки. На мобильном cy=2427, шрифт SVG увеличен для читаемости.

## Сохранённая модель

В ZIP пользователя Supercharged LS V8 Engine 1 находится FBX без текстур, с одним белым материалом. scripts/prepare-model.mjs преобразует его в public/models/ls-v8.glb и назначает графитовые, стальные и красные материалы. Группы деталей заданы приблизительно по пространственному положению; внутренние поршни — схема. Автор и лицензия не указаны в исходном архиве; поля атрибуции сохранены для заполнения до публикации.

## React Bits

components.json сохраняет настройку shadcn и реестров React Bits. Клиент не обращается к MCP и не содержит лицензионного ключа. Для локального доступа к Pro нужен REACTBITS_LICENSE_KEY в окружении или игнорируемом .env.local; наличие настройки не подтверждает право доступа к платным компонентам. Текущий hero реализован собственными SVG/CSS/GSAP без платного шаблона.
