# MotorServiceKRD

Сайт автосервиса на React + TypeScript + Vite, Tailwind CSS, GSAP и Three.js. Текущая версия включает контент v4.1, полноэкранный видео-hero с собственным плеером и плавную фотоленту.

- Сайт: https://switch3344.github.io/MotorS/
- Репозиторий: https://github.com/switch3344/MotorS

## Запуск и сборка

```powershell
npm ci
npm run dev
npm run check
npm run build
npm run preview
```

## Текущая версия

- Hero: «Мощность требует ухода» в одну строку, без подзаголовка и кнопки записи. Нативное видео на всю карточку с чёрными боковыми полями; короткое беззвучное превью сменяется монтажом по нажатию «Смотреть разгон». Монтаж 21.2 с: прерывистый разгон, затем чёрный финал с рисующейся дугой и оффером. Только оригинальный звук двигателя, без озвучки. 1080p Lanczos + мягкая CAS-резкость; исходник остаётся 720p по детализации. Исходный процедурный спидометр и шейдер удалены.
- Плеер: отдельный кинорежим через нативный dialog, без шапки и прокрутки. Видео постоянно смонтировано и не перезапускает загрузку при открытии. Пауза — нажатием на кадр, Enter или Space. Нижнего таймлайна нет; небольшие верхние иконки скрываются при просмотре. Вытянутая тёмная кнопка просмотра плавно следует за курсором; выход — кнопкой «Закрыть видео» или Escape.  После выхода восстанавливаются фокус, прокрутка и превью. Видео останавливается вне hero и в скрытой вкладке; reduced-motion отключает автопревью. Подготовка, источники и ограничения — `docs/HERO-VIDEO.md`.
- Полоса показателей и минималистичная фотолента из восьми реальных снимков мастерской. Кнопки, свайп/перетаскивание и клавиши ← / → перелистывают ленту; нажатие открывает крупное фото, Escape закрывает просмотр.
- Контент ограничен фактами пользовательского ТЗ v4.1, атрибутированного @MSERVICEKRD. Неизвестные данные обозначены `{{...}}`. Фотографии происходят из отдельных альбомов канала, список источников — `docs/WORK-PHOTOS.md`; они не выданы за снимки трёх кейсов v4.1.
- Список услуг всегда виден, «Диагностика» открыта по умолчанию. Вместо разборки V12 используется предоставленная пользователем модель Inline 4 с рабочей анимацией. Камера вписывает увеличенный двигатель с левого ракурса в обе оси холста; пауза и запуск выполняются нажатием на саму модель, нижней кнопки нет. Подробности — `docs/ENGINE-INLINE4.md`.
- Основные заголовки используют TechText из React Bits: буква превращается в пунктирный контур при наведении, при клике пружинит. Сохранены семантика заголовков, нативный текст и статичный режим reduced-motion. Источник и лицензия — `src/components/TechText/LICENSE.txt`.
- Рабочий механизм: поршни, шатуны, коленвал, распредвалы, клапаны, пружины и ГРМ. Исходные drivers запечены в бесшовный цикл 8 с; 7.73 MB GLB с локальным Draco-декодером. Полная геометрия исходника сохранена; неподвижные детали объединены для снижения draw calls, анимация останавливается вне экрана и в фоновой вкладке.
- Прелоадер ждёт два отрисованных кадра двигателя с материалами, освещением и тенями. Canvas монтируется сразу и сохраняется после загрузки; при ошибке используется poster. Страница недоступна для взаимодействия до готовности.
- Кнопки записи белые, с круглой градиентной иконкой ↗. Высота 56 px, в шапке 44 px. Отдельная кнопка Telegram в шапке удалена. Счётчики фотоленты используют Manrope; видимые пометки подтверждения удалены без добавления новых фактов.
- Промежуточные секции идут во всю ширину, без скруглений и чёрных зазоров. У hero скруглён только верх; футер сохраняет фигурный вырез.
- Фотолента использует непрерывную позицию вместо смены CSS-слотов; скрытая перестановка карточек сохраняет плавность 08 → 01. Удалена прямоугольная плоскость ContactShadows под двигателем; собственные тени деталей сохранены.
- Шапка увеличена: до 1600 px по ширине, 96–112 px в исходном состоянии, 80–96 px при прокрутке; логотип и ссылки масштабируются. При начале прокрутки отделяется сразу, её фигурные вырезы скрываются; в исходном положении фон примыкает к верхней границе без щели.
- Навигация: нативные плавные якоря с отступом 110 px, aria-current для выбранного раздела, поддержка истории. На мобильном меню закрывается при выборе, Escape и нажатии снаружи. В блоке «Оригинал или ничего» убраны номера.
- Логотип в шапке и футере — прозрачный PNG без белых CSS-подложек. Исходник сохранён; результат и описание обработки — `docs/LOGO-ASSET.md`.
- Футер — #0A0A0A без декоративной подложки, с сохранённым фигурным вырезом.
- При reduced-motion превью не запускается автоматически, двигатель начинается со статичной модели и запускается только по явному нажатию.

## Видео для hero

`public/video/gtr_final_ready_v9.mp4` — монтаж по сценарию пользователя из ролика Авторевю о Nissan GT-R. `gtr-preview-v5.mp4` — беззвучное превью, `gtr-poster-v2.jpg` — poster. Источник указан в финале ролика и в документации. Озвучки нет. Сценарий рендера — `scripts/render-user-montage.py`; подробности и воспроизведение сборки — `docs/HERO-VIDEO.md`.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает и публикует `dist` после push в `main`; доступен ручной workflow_dispatch. Источник Pages — GitHub Actions. В workflow задан `VITE_BASE_PATH=/MotorS/`; локально используется `/`.

## Контент и модели

- `src/config/content.config.ts` — показатели, архив данных кейсов v4.1 и текущие фото. Фотолента заменила карточки кейсов по новому запросу пользователя.
- `src/config/site.config.ts` — контакты и общая гарантия; телефон пока не подтверждён.
- `src/components/EngineScene/EngineModel.tsx` — воспроизведение рабочей модели, пауза и вписывание камеры. Оригинальный `.blend` сохранён в `assets-source/inline4`.
- `src/components/TechText` — TechText и адаптер к существующим заголовкам.
- `src/components/Hero/SpeedometerVideo.tsx` — нативное управление кадром без нижнего таймлайна.
- `public/models/motorservice-v12.glb` — предыдущая презентационная 3D-модель, сохранённая для истории; создана `scripts/generate-v12.py`; надписи удалены. Исторические `.blend` и студийный снимок находятся в `assets-source/v12`.
- Предоставленный ранее LS V8 сохранён отдельно и не используется текущей страницей.

## React Bits

`components.json` сохраняет конфигурацию shadcn и реестров React Bits. Для установки платных компонентов нужен `REACTBITS_LICENSE_KEY` в окружении или игнорируемом `.env.local`. Клиент не содержит ключа и не обращается к MCP. Плеер использует нативные HTML video; дополнительная библиотека для видео не нужна.
