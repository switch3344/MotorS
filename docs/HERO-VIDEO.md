# Локальное видео и плеер

12 ноября 2026. Текущая подготовленная версия использует MP4 вместо YouTube iframe.

- Источник по ссылке пользователя: https://www.youtube.com/watch?v=3LI1MHnLwB0 — Авторевю, Nissan GT-R. Исходник сохранён локально в игнорируемой .qa/source-gtr.mp4.
- public/video/gtr-preview-v3.mp4 — беззвучное восьмисекундное превью. public/video/gtr-poster-v1.jpg — кадр загрузки.
- public/video/gtr_final_ready.mp4 — монтаж по присланному пользователем коду: 22 секунды разгона, А (0.65), рывок 18.5–19.15, ВЫ ХОТИТЕ (0.75), рывок 20.8–21.45, ТАК ЕЗДИТЬ? (0.85), размытый финал 16–19.5 с оффером. Фактическая длительность 29.13 секунды из-за округления вставок к целым кадрам 30 FPS.
- Озвучки нет. В чёрных текстовых вставках тишина, в рывках усилен оригинальный звук с limiter от клиппинга, в финале звук затухает. Attribution источника сохранена в финале и ссылке под плеером.
- H.264 1280×720, yuv420p, AAC stereo; +faststart, ключевой кадр раз в секунду, без B-кадров, один reference frame. Файл 8.85 MB. Полная проверка декодирования FFmpeg прошла без ошибок.

Повторная сборка:

```powershell
python scripts/render-user-montage.py --ffmpeg C:/path/to/ffmpeg.exe --input path/to/source.mp4
```

При необходимости --font указывает путь к Impact TTF. Шрифт Windows не распространяется в репозитории.

Плеер: два стабильных video-элемента; превью остаётся до первого кадра полного видео. Тихая подготовка файла, без смены src/load при клике. Таймлайн обновляет только свои DOM-узлы; перетаскивание выполняет seek при отпускании, клавиатура с debounce 140 ms. Во время прокрутки за пределы hero и в скрытой вкладке видео останавливаются. Полноразмерный фон и чёрные боковые полосы сохранены. Заголовок «Мощность требует ухода» — одна строка, без кавычек и кнопки записи в hero.

На тестовом отрезке полного исходного видео после оптимизации: 0 пропущенных кадров из 328, 0 buffer stalls, readyState=4. Это измерение в конкретной локальной проверке, не гарантия для всех устройств. Оформление плеера пока остаётся временным в ожидании референса пользователя.

Проверка готового монтажа в браузере: запуск со звуком, повтор и перемотка работают; полный прогон показал 2 пропущенных кадра из 874, 0 buffer stalls. После повторного запуска и перемотки — те же 2 пропуска из 1356 суммарных кадров, без новых stalls. TypeScript check и сборка с VITE_BASE_PATH=/MotorS/ прошли.
