## Монтаж v2

`public/video/gtr_final_ready_v2.mp4`: 1280×720, 30 FPS, H.264 yuv420p, AAC stereo 48 kHz, около 21.17 с. H.264 fastdecode, ключевой кадр раз в секунду, без B-кадров, один reference frame, faststart.

1. Чёрная вставка «А» — 0.65 с, тишина.
2. Рывок двигателя: исходник 9.8–10.45.
3. «ВЫ ХОТИТЕ» — 0.75 с, тишина.
4. Рывок двигателя: исходник 13.2–13.85.
5. «ТАК ЕЗДИТЬ?» — 0.85 с, тишина.
6. Основной разгон: 0–14.03 с исходника. На отметке 14.0 с приборка показывает 200 км/ч. Более поздних кадров разгона нет, включая вставки.
7. Размытый финал с оффером — исходник 10.5–14.0, звук плавно затухает.

Озвучки нет. Усиленные звуковые вставки ограничены limiter от клиппинга. Полное декодирование FFmpeg прошло без ошибок. Предыдущий монтаж сохранён локально в `.qa/gtr_final_ready-v1.mp4`.

`gtr-preview-v3.mp4` — восьмисекундное беззвучное превью, `gtr-poster-v1.jpg` — poster. Это отдельные стабильные video-элементы; превью остаётся до первого playing-кадра монтажа. Источники не меняются при клике. Таймлайн обновляет только собственные DOM-узлы и выполняет seek при отпускании, клавиатура — debounce 140 ms.

Круглая кнопка «Просмотреть видео» плавно следует за указателем через GSAP quickTo; на touch и reduced-motion она статична. Управление — тонкая двухпиксельная шкала с компактными кнопками. Клик по кадру переключает паузу. Кнопка «Закрыть видео» и Escape возвращают беззвучное превью; звук выключается. Вне hero и в скрытой вкладке воспроизведение останавливается. Заголовок при просмотре скрывается и возвращается после выхода.

Повторная сборка:

```powershell
python scripts/render-user-montage.py --ffmpeg C:/path/to/ffmpeg.exe --input path/to/source.mp4
```

`--font` задаёт Impact TTF; Windows-шрифт в репозитории не распространяется. Известные замеры предыдущей версии плеера: 2 dropped frames / 874, 0 buffer stalls; после повторного запуска и seek — 2 / 1356. Это конкретный локальный замер, а не гарантия для всех устройств. Текущая версия проверяется отдельно.

Проверки v2: сборка TypeScript/Vite прошла; полный локальный прогон — 0 dropped frames из 595 на 19-й секунде, 0 buffer stalls. Кнопка выхода и Escape возвращают preview/muted=true. Измеренный transform круглой кнопки после движения указателя: translate(612.5px, 350px), без обновлений React на каждом pointermove.
