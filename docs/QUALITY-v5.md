# Hero v5.1 и плавная фотолента

12 ноября 2026. Сборка с VITE_BASE_PATH=/MotorS/.

Пять проходов:

1. Композиция: плотный заголовок «Капитальный ремонт двигателя», белые primary 56 px / шапка 44 px, круглые иконки 40/32 px. Единые поля 8 px и постоянный gutter. Прозрачная secondary для разбора двигателя.
2. Прибор: радиус 3200, концы дуги ±18° вне viewBox, preserveAspectRatio=xMidYMid slice. Подписи шкалы уменьшены, стрелка 62 px desktop / 38 px mobile; заполнение без фильтров. Табло, дорога, безель и шум не возвращались.
3. Шейдер: два прохода с float16 target, дезеринг только при выводе. Проверено состояние webgl-float без ошибок консоли. Свечение идёт по той же окружности, что и прибор. Медленное дыхание ±8%, дрейф, раскрытие веера; плавная реакция на обороты +15%. Лимит 60 FPS, адаптация буфера, пауза вне hero и скрытой вкладки, статичный reduced-motion / CSS fallback. Под двигателем удалён ContactShadows, создававший видимый прямоугольник.
4. Фотолента: непрерывная позиция GSAP, перестановка при |slot| около 4 происходит при нулевой прозрачности. Смягчены поворот и масштаб, убрано увеличение фото при наведении. Переходы при быстрых нажатиях продолжаются с текущей позиции, без CSS-перескоков. Reduced-motion без интерполяции.
5. TypeScript и production build прошли. Desktop 1440×900 проверен в браузере; mobile 390×844: поля [8,8], горизонтальное переполнение 0, зазор от кнопки до вершины горизонта 199 px. Вне hero шейдер перешёл в paused. Промежуточный Lighthouse desktop: Performance 90, Accessibility 97, CLS 0, TBT 240 ms (перед последними небольшими правками траектории свечения и ленты; .qa/lighthouse-v5-desktop.json).

Ограничения проверки: отдельные замеры CPU ≤10%, настоящий browser zoom 300%, reduced-motion на устройстве и Lighthouse mobile не подтверждены. Это не выдано за пройденные измерения. Видео и poster не присланы: вместо них используется шейдер согласно v5.1. React Bits Pro недоступен без ключа, фон реализован собственным кодом Three.js.
